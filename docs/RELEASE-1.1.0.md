## リリース後30日間の購入確認手順

目標は親Issue #43の「1件以上のPro購入」。公開日2026-10-19を起点に、30日後の2026-11-18に集計結果を確認する。これは確認手順の記録であり、定期実行・通知の設定ではない。

1. App Store ConnectのSales and Trendsで対象アプリとPro商品を選び、公開後30日間の新規購入件数を確認する。タイムゾーンとレポート反映遅延を確認し、必要なら反映後に再集計する。
2. 購入の復元・TestFlight/Sandboxのテスト取引を、新規の本番購入に数えない。
3. 対象期間、集計日時、新規購入件数、返金の有無を#47または#43に記録する。現時点の購入件数は未確認。
4. 本番購入が1件以上なら売上目標達成として記録する。未達の場合も、公開・検証作業の完了とは分け、ブログ流入・ダウンロード・利用者の感想を確認して次の施策を選ぶ。
