RUNNING RACE MATE

プライバシーポリシー

最終更新日: 2026年10月22日

Running Race Mate（以下「本アプリ」）は、レース当日の準備を支援するためのアプリです。本ポリシーでは、本アプリにおける情報の取り扱いを説明します。

収集する情報

本アプリは、個人情報を収集しません。

レースプラン、持ち物チェック、メモなど、利用者が入力した内容は利用者の端末に保存されます。本アプリは、これらの情報を本アプリの外部サーバーへ送信しません。端末のバックアップを復元した場合、保存したレースプランやメモも新しい端末に復元されます。

通知

本アプリは、利用者が許可した場合に限り、レース前や持ち物の期限に合わせたローカル通知を端末上に登録します。通知の送信に外部サーバーは使用しません。通知の許可は、端末の設定からいつでも変更できます。

第三者への提供

開発者は、本アプリに入力されたレースプラン、持ち物チェック、メモなどを収集せず、第三者へ提供・販売しません。

利用者がRace Cardの保存・共有・印刷を行った場合は、選択した保存先・共有先・プリンタへ、出力内容が渡されます。共有先での情報の取り扱いは、各サービスのポリシーをご確認ください。

外部サービス

本アプリは、ログイン、広告、アクセス解析、トラッキングSDKを使用しません。

追加機能「Running Race Mate Pro」は、AppleのApp Storeを通じた買い切りのアプリ内課金で提供します。商品情報の取得、購入、購入の復元、購入状況の確認にはAppleのStoreKitを使用します。

本アプリは、StoreKitから得られる商品・取引情報を端末上で検証し、Pro機能の利用可否を判断します。購入処理にはAppleとの通信が必要ですが、レースプランやメモを購入処理のために送信することはありません。開発者がクレジットカード番号などの決済情報を取得することはありません。Appleによる購入・決済情報の取り扱いは、Appleのプライバシーポリシーをご確認ください。

お問い合わせ

本ポリシーに関するお問い合わせは、お問い合わせフォームからお願いします。

本ポリシーの変更

本アプリの機能または情報の取り扱いを変更する場合、本ポリシーを更新します。更新後の内容は本ページに掲載します。
