# レース補給メモ

レース補給メモは、ランナーがマラソンや10kmレース前に、レースプラン、通過タイム、補給タイミング、持ち物チェックリスト、メモ、ローカル通知をまとめて管理するためのiOSアプリです。

単なるペース計算機ではなく、レース当日までに確認したい情報を1つのレースプランとして保存できることをMVPの中心価値にします。

## MVP方針

今日中にMVPを完成させ、App Store Connectへアップロードし、可能なら審査提出まで進めることを目標にします。

最初から作り込みすぎず、以下を優先します。

- App Store審査に出せる最低限の完成度
- 主要導線でクラッシュしないこと
- 外部通信やログインを使わず、端末内だけで完結すること
- SwiftUI標準UIによる実装速度と安定性
- 日本語UIとして自然に使えること

## 計算仕様

### 目標ペース

- totalMinutes = targetHours * 60 + targetMinutes
- pacePerKm = totalMinutes / distanceKm
- 表示例: 4分58秒/km

### 5kmごとの通過タイム

- フル: 5km、10km、15km、20km、25km、30km、35km、40km、42.195km
- ハーフ: 5km、10km、15km、20km、21.0975km
- 10km: 5km、10km
- 5km: 5km

### 補給タイミング

- gelCountが0なら「補給予定なし」
- フルは10km〜35kmの間に均等配置
- ハーフは中間地点中心
- 10km以下は必要なら中間地点
- 表示例: 10km地点、18km地点、26km地点

## App Store審査に向けた前提

- アプリは外部通信を行わない
- 個人情報を収集しない
- 広告、課金、解析SDKを含めない
- ログインやアカウント作成を要求しない
- 免責事項とプライバシーポリシーはアプリ内で読めるようにする
- レース準備を補助するメモアプリであり、医療・健康上の助言を提供するものではない
- 通知はUserNotificationsによるローカル通知のみを使う

## 開発判断基準

MVP中に迷った場合は、以下の順で判断します。

1. 今日中のMVP完成と審査提出に近づくか
2. 主要導線の安定性を上げるか
3. App Store審査で必要な説明や安全性に関係するか
4. スコープ外機能を増やしていないか

上記に当てはまらない作り込みは、MVP後のIssueとして扱います。
