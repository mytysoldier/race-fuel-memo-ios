# レース補給メモ

レース補給メモは、ランナーがマラソンや10kmレース前に、レースプラン、通過タイム、補給タイミング、持ち物チェックリスト、メモ、ローカル通知をまとめて管理するためのiOSアプリです。

単なるペース計算機ではなく、レース当日までに確認したい情報を1つのレースプランとして保存できるアプリを目指します。

## アプリ概要

レース前は、目標タイム、スタート時刻、補給のタイミング、持ち物、当日の注意事項など、確認すべき情報が分散しがちです。レース補給メモは、それらをレースごとのプランとしてまとめ、当日までに何を確認すればよいかを見失わないようにするためのアプリです。

ユーザーはレース名、開催日、スタート時刻、距離、目標時間、補給ジェル数、メモを入力してレースプランを作成します。作成したプランでは、目標ペース、5kmごとの通過タイム、補給タイミング、持ち物チェックリストをまとめて確認できます。

データは端末内に保存し、ログインやサーバー連携を必要としません。外部通信、広告、課金、解析SDKを使わず、レース前の準備に集中できるシンプルな日本語UIを重視します。

## 主な機能

- レースプランの作成、一覧表示、詳細確認、削除
- 距離と目標時間からの1kmあたりの目標ペース表示
- 5kmごとの通過タイム表示
- 補給ジェル数に応じた補給タイミング表示
- レースごとの持ち物チェックリスト
- レース前メモの保存
- レース前日の夜、当日スタート前に確認を促すローカル通知
- 免責事項とプライバシーポリシーを含む設定/情報画面

## 開発

Xcodeで `RaceFuelMemo.xcodeproj` を開き、`RaceFuelMemo` スキームを実行します。

コマンドラインでビルド確認する場合:

```sh
xcodebuild -project RaceFuelMemo.xcodeproj -scheme RaceFuelMemo -configuration Debug -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```
