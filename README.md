# Running Race Mate

Running Race Mateは、ランナーがマラソンや10kmレース前に、レースプラン、通過タイム、補給タイミング、持ち物チェックリスト、メモ、ローカル通知をまとめて管理するためのiOSアプリです。

単なるペース計算機ではなく、レース当日までに確認したい情報を1つのレースプランとして保存できるアプリを目指します。

## アプリ概要

レース前は、目標タイム、スタート時刻、補給のタイミング、持ち物、当日の注意事項など、確認すべき情報が分散しがちです。Running Race Mateは、それらをレースごとのプランとしてまとめ、当日までに何を確認すればよいかを見失わないようにするためのアプリです。

ユーザーはレース名、開催日、スタート時刻、距離、目標時間、補給ジェル数、メモを入力してレースプランを作成します。作成したプランでは、目標ペース、5kmごとの通過タイム、補給タイミング、持ち物チェックリストをまとめて確認できます。

データは端末に保存され、本アプリの外部サーバーへ送信されません。ログインや独自サーバーとの連携は不要で、広告・解析SDKは使用しません。基本機能は無料で利用でき、詳細な計画・出力機能は買い切りのアプリ内課金「Running Race Mate Pro」で提供します。商品情報の取得、購入、購入の復元にはAppleのStoreKitを使用します。

## 主な機能

- レースプランの作成、一覧表示、詳細確認、削除
- 距離と目標時間からの1kmあたりの目標ペース表示
- 5kmごとの通過タイム表示
- 補給ジェル数に応じた補給タイミング表示
- レースごとの持ち物チェックリスト
- レース前メモの保存
- レース前日の夜、当日スタート前に確認を促すローカル通知
- Race Cardの画像・PDF保存、共有、印刷とペースバンド出力
- 免責事項とプライバシーポリシーを含む設定/情報画面

## 無料とPro

無料でレースの作成・保存・履歴、基本編集、基本のペース・固定区間の通過計算、標準チェックリストを利用できます。
Proは非消耗型の買い切りで、詳細な地点・ペース・補給の設定、チェックリスト拡張、計画の複製・再利用、Race Card出力、準備状況ダッシュボードを利用できます。価格はアプリ内の購入画面で確認できます。保存済みのレースや詳細データの閲覧、既存項目のチェック状態の変更は無料です。

## Race Card出力（Pro）

レース詳細の「画像・PDF・ペースバンド出力」から、基本計画またはA・B・Cプラン、ランナー本人向け／サポート向け、通常カード／ペースバンドを選べます。大会・目標、区間ペース、通過時刻、関門、補給・受け取り方法、メモを出力します。選択は出力だけに適用され、保存済みの計画は変更しません。

PNG画像とPDFは「ファイル」に保存するか、共有シートから共有できます。内容が多い場合は文字を縮めず複数ページに続け、全ページをプレビューできます。ペースバンドは180 × 55 mmの切り取り枠をA4に配置します。保存したPDFを外部から印刷する場合は100%（実際のサイズ）を指定してください。アプリ内の印刷ではプリンタの印刷可能領域に合わせて帯を原寸で配置します。
